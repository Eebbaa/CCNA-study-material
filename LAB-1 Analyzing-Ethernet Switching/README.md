# Analyzing Ethernet Switching

This folder contains study notes and hands-on labs focused on analyzing Ethernet switching behavior as part of CCNA preparation.

## Objectives
- Understand how Ethernet switches forward frames
- Analyze MAC address learning and aging
- Examine switch forwarding methods and frame processing
- Identify and troubleshoot common Layer 2 switching issues

## Topics Covered
- MAC address table (CAM table)
- Frame forwarding and filtering
- Flooding and broadcast behavior
- Unicast, multicast, and broadcast frames
- Switch forwarding methods (store-and-forward, cut-through)
- Collision domains vs broadcast domains
- Duplex settings and interface speed

## Labs
- Observing MAC address table population
- Analyzing frame forwarding using Packet Tracer
- Identifying unknown unicast flooding
- Verifying switch port behavior

## Tools Used
- Cisco Packet Tracer
- Visual Studio Code
